# ToDo リスト Web アプリ

Next.js（JavaScript）で作った、シンプルで使いやすい ToDo リストアプリです。

## 主な機能

- タスクの追加・完了マーク・削除
- `localStorage` によるデータ永続化（ブラウザを閉じても消えません）
- 未完了 / 完了でのフィルタリング、完了済みタスクの一括削除
- 温かみのある、読みやすく操作しやすい UI

## 使用技術

- [Next.js](https://nextjs.org)（App Router / JavaScript）
- React
- CSS Modules

## ローカルでの実行方法

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) をブラウザで開いてください。

## ビルド

```bash
npm run build
npm run start
```
